# 自适应 AI 互动学习系统：产品需求文档

版本：0.3 · 更新日期：2026-09-26 · 状态：一期全学科演示开发基线，尚未实现

本文规定产品范围、教学规则与验收标准；接口、字段和运行时行为见[前端和 Agent 交互方式](前端和Agent交互方式.md)。两份文档中的 `v1` 指应用协议版本，与 CLI 版本无关。

## 1. 产品定位与范围

面向个人学习者的本地 Web 学习工作室，以“目标规划 → 单概念讲解与交互演示 → 练习 → 错因诊断 → 必要补课 → 验证掌握”为核心闭环。**一期即尽量覆盖从中小学到大学、从基础科学到计算机和人工智能的教程演示**，以可复用的图形、实验和计算组件支撑按需生成课程。课程内容、进度、作答和笔记保存在本机；在线生成和答疑通过用户自己的 Antigravity CLI 运行。

### 1.1 已确定的产品约束

- 一期只支持 **Antigravity CLI（可执行命令 `agy`）**，不支持 Claude Code 或其他 Agent 运行时，不接入独立模型 API。
- 只供个人本地使用。用户自行安装 CLI、完成官方登录，并承担自己账号的额度使用；应用不安装、升级 CLI，不接管登录，不收集账号凭证。
- 前端、应用服务和 CLI 在同一台计算机运行，服务只监听回环地址。不提供 SaaS、多人账号、局域网访问、跨设备同步或后台代用户调用。
- 一期以 Windows 11 和当前稳定版 Edge/Chrome 为验收环境；macOS/Linux 在独立验证后再承诺支持。
- 已下载的课程可离线阅读、做可确定判分的题、记笔记和导出。Agent 讲解、生成与诊断需要 CLI 和网络可用。
- 使用用户已有 CLI 登录和额度，不承诺无限使用、必然包含在某一订阅中或零费用；额度与模型可用性以 CLI 实际反馈为准。不得自动切换付费 API。
- 教学状态由本地规则和数据库决定。Agent 提供内容和诊断建议，不能直接把节点标记为“已掌握”或任意改写数据库。

### 1.2 一期与后续能力

| 能力 | 一期必做 | 后续扩展 |
| --- | --- | --- |
| 学科 | 第 1.3 节全部学科组的代表性教程、交互演示与专项验证；新主题复用这些能力按需生成 | 随实际学习主题持续增加更深的专业模板，而非把整门学科推迟 |
| 课程 | 目标与背景输入、先修诊断、可编辑大纲、按节点生成、多课程切换与归档 | 更复杂的长期学习计划 |
| 教学 | 单概念讲解、确定性练习判分、错因诊断、受控补丁、间隔复习 | 主观证明题与更精细的学习模型 |
| 渲染 | Markdown、公式、二维/三维几何、函数/曲面/向量场、矩阵、统计图、物理实验、电路、分子、生物过程、算法与网络、ML/DL 演示 | 超出个人设备能力的高精度大型仿真 |
| 导师 | 绑定当前段落或组件状态的流式多轮问答、取消、恢复历史 | 语音等输入 |
| 练习与计算 | 单选、多选、数值填空、受控参数题；小型 JS/Python/SQL 代码实验和 ML/DL 计算反馈 | 任意系统工程的编译运行与通用代码裁判、开放证明与长文本评分 |
| 数据 | SQLite 持久化、笔记、错题记录、`.learn` 导入导出、Markdown 导出 | 静态 HTML/PDF 导出 |
| 分享 | 用户自行分发不含个人记录的 `.learn` 文件 | 如有需要再设计云端分享；不属于本地一期 |

一期支持安全受限的小型计算实验，不能仅用代码高亮替代计算机学科演示。全学科覆盖指具备生成和呈现各学科教程的能力及代表性样例，不要求发布前预写所有专业的完整教材，也不声称所有新生成内容都已经学术核验。各学科内部可以按基础→进阶逐步交付，但以下覆盖矩阵属于**同一个一期**的完成标准。

### 1.4 演示边界与允许后置的功能

优先采用现成渲染库、可解释解析模型、有限规模数值计算和小型真实实验。区分并标明 **真实计算、简化模型、预计算数据、过程示意**；播放预录轨迹不能标成当前参数下的实时计算，动画也不能假装证明结论。

| 可以后置的高难能力 | 一期仍须保留的教学表达 |
| --- | --- |
| 工业级 CFD/有限元、多物理场耦合与高精度大规模 PDE 求解 | 解析解、低分辨率小模型、关键参数曲线、公开预计算剖面 |
| 从任意分子自动求稳定三维构象、量子化学/分子动力学与可靠反应预测 | 二维结构、已有坐标模型、能级/机理示意、简单速率和平衡计算 |
| 真实器官级生理、全细胞或复杂生态系统精确预测 | 有来源的结构图、阶段过程与显式假设的低维模型 |
| 大模型从零训练、GPU 集群和超大数据集计算 | 小网络真实训练、单层/单步张量计算、小型注意力、预计算大型模型结果 |
| 任意语言/项目/系统服务的通用运行环境、内核/网络实机实验 | 小型 JS/Python/SQL 实验、算法与系统机制模拟，不访问真实主机/网络 |
| 所有学科的完整自动证明与开放问题可靠裁判 | 公式推导、可核对步骤、确定性客观题，主观答案提供形成性反馈 |

不得仅以“学科高级”“需要三维”“模型复杂”为由将整门学科推迟。若具体一期模板无法完成，应记录受阻原因、已尝试方案、一期替代演示与剩余工作；基础文本可作为故障降级，但不能代替该学科组正常环境下的演示验收。

## 2. 首次使用与主要流程

### 2.1 环境准备

1. 用户自行安装并登录 Antigravity CLI。
2. 启动本地应用；应用检测 CLI 路径、版本和已验证参数。检测失败仍可进入已有课程的离线模式。
3. 用户触发一次最小连通性检查，界面说明该检查会使用少量 CLI 额度。显示就绪、未登录、版本不兼容、网络不可用或额度受限；无法区分的错误显示原因为未知，不猜测。
4. 呈现 CLI 当前权限策略及本地运行说明；不修改用户的 CLI 权限或全局配置。

### 2.2 创建并学习课程

1. 输入主题、具体学习目标、已有基础、每周可投入分钟数及语言。可选目标日期；目标与时间明显不匹配时给出调整建议，不承诺达成日期。
2. Agent 生成待确认大纲：学习目标、节点依赖、先修概念、预计时长及来源。用户可调整范围后确认。确认前不批量生成整本教材。
3. 对声明已会的前置节点提供可跳过的诊断测验。跳过诊断不等于掌握；用户可明确选择“先继续”，保留绕过标记。
4. 进入一个节点，按需生成讲解、例题和练习。每节点 1～3 个可测量目标，预计 5～15 分钟，只引入一个核心概念。
5. 提交练习后先显示本地判分，再异步提供 Agent 错因分析。Agent 不可用不影响已确定的判分和记录。
6. 满足规则后解锁后续节点；出现重复错误则补充解释或进入受控补课流程。

### 2.3 学习工作室

- 左侧导航展示章节与依赖关系的树形投影；同一知识节点只有一份进度，不因出现在多个分支而重复计数。
- 主区展示正文、图形、来源、题目及笔记。无效图形显示替代说明和“重新生成”入口，不导致整个节点不可读。
- 右侧导师窗展示当前提问引用的段落或组件，允许用户清除或更换引用。答疑默认只写聊天历史，不自动修改正文、大纲或进度。
- 支持明确的“修改讲解”操作：生成新草稿，用户预览确认后替换；历史正文和作答版本可追溯。
- 演示提供参数说明、开始/暂停、单步、复位和必要的时间轴；不同视图共享同一份实验状态。例如物体运动、能量曲线和数值读数必须同步，不能各播放不相关动画。
- 导师可获得当前选中原子/图节点、算法步骤、实验时刻、张量形状与训练轮次等语义状态。演示结果可保存为笔记快照，但运行成功或播放结束不直接算掌握。
- 生成中可取消；排队、重试、离线、额度不足和中断状态必须可见。关闭页面不默认取消后台任务，重新打开可查看其状态。
- 多标签页可阅读同一课程；同一导师会话同一时刻只允许一个未结束请求，服务端负责限制。

## 3. 掌握度判定：规则 `mastery-v1`

### 3.1 基本概念

- `objectiveId`：节点中的可测量学习目标，每道题只关联一个主要目标。
- `exerciseId`：具体题目；`familyId`：题目家族。同一道题重试、换数字或选项换序不算新的独立证据。
- `cycleId`：该节点的一轮学习/验证。正文核心目标或判分规则改变、完成补丁后返回主节点、开始复习时开启新轮；历史记录保留。
- `remediationEpochId`：同一次尚未达标的学习阶段，可包含补丁前后的多轮验证；补丁次数在这些轮之间累计。达标后再次复习才开启新阶段。
- 题目分配时由服务端记录暴露状态。提示、解析、参考答案被展示后，该题本轮不能贡献独立答对证据。
- 新验证轮使用历史未作答过的题目家族；已见家族可复练，但不进入新轮证据窗口。没有新题且离线时保留进度，提示联网补题。
- 验收题库须人工核对家族标签与答案；模型生成的新家族只是候选，须通过结构、重复题干与对应模板校验。此规则不声称能自动证明语义独立性。

### 3.2 判分与证据

| 题型 | 本地判分规则 |
| --- | --- |
| 单选 | 选项 ID 完全匹配 |
| 多选 | 选项集合完全相等；重复选项视为非法输入，一期不设部分分 |
| 数值填空 | 数值有限，且 `abs(actual-expected) <= max(absTolerance, relTolerance * abs(expected))`；容差必须随题给出，单位使用预定义转换表 |
| 参数题 | 对允许的数值参数计算预定义判分模板；不执行 Agent 提供的代码或表达式 |

格式非法的答案返回输入错误，不创建作答证据。主观问答只用于形成性反馈，一期不改变掌握度。答案键存在争议时，用户可标记题目无效；相关证据排除并重新计算，保留审计记录。

对每个目标，在**当前轮**按时间取最近最多 5 个不同 `familyId` 的有效首答；同一家族只取本轮第一次有效提交：

```text
evidenceScore = 1，当且仅当判分正确且提交前未用提示、未看解析或答案；否则为 0。
n = 当前窗口证据数
evidenceRate = sum(evidenceScore) / n；n=0 时不显示比例
目标达标 = n >= 2 且 evidenceRate >= 0.8
节点达标 = 每个目标均达标
```

例如 2/2、3/3、4/5 达标；1/1、2/3、3/5 不达标。首答错误后的同题重做可以显示“本次答对”，但不会覆盖该家族的首次证据。新的独立题允许旧证据逐渐移出窗口。

“已掌握”表示满足产品的当前证据标准，不代表心理测量意义上的掌握概率。界面展示“独立作答证据 4/5”等可解释信息，不显示模型虚构的掌握百分比。

### 3.3 节点状态与解锁

| 状态 | 含义及转换 |
| --- | --- |
| `locked` 未解锁 | 至少一个先修节点未曾达标，且用户未显式绕过 |
| `available` 可学习 | 先修条件满足，还未开始本节点 |
| `learning` 学习中 | 已进入、验证中或主动重新学习；全部目标达标后转为 `mastered` |
| `mastered` 已掌握 | 当前轮达标，并记录首次/最近达标时间 |
| `review_due` 待复习 | 达到复习时间，或已掌握内容因题目作废等原因需要复核；开始复习后转 `learning` |

- 解锁依据 `masteredOnce` 和显式的绕过记录，而非颜色。普通复习到期不重新锁住已经可访问的后续内容。
- 绕过不制造掌握证据，界面单独标记“已跳过先修条件”，可以撤销。已有学习记录不因撤销而删除。
- 新插入的补丁是目标节点本次验证的额外条件；补丁未完成时可继续阅读主节点，但不能结束本次验证。既有后续节点不被追溯锁定。
- 课程确认后对目标或依赖的人工更改生成新版本；受影响节点重新验证，不把旧题证据无条件迁移到新目标。
- 达标后的学习轮关闭；用户选择“继续练习”时开启新的复习轮，不向已关闭的轮追加掌握证据。

### 3.4 复习

初次达标后分别按 1、3、7、14 天安排下一次复习，间隔从上次成功验证的完成时间算起，后续维持 14 天。使用 UTC 时间存储、按本地时区显示。

复习开启新 `cycleId`，每个目标先分配两个新题家族，按同一达标规则判定。两题中有失败则留在学习中，继续生成新独立题；成功后推进复习阶段。若进入补课，则复习阶段归零，下次达标后按 1 天安排。提醒只在本地应用内展示，不要求后台常驻通知。

## 4. 错因诊断与课程补丁：规则 `remediation-v1`

### 4.1 触发与分流

每次错误首答可以触发异步诊断，返回 `errorType`、引用的 `attemptIds`、`objectiveId`、解释、建议和置信度。错误类型限定为 `slip`（操作疏忽）、`misconception`（概念误解）、`prerequisite_gap`（先修缺口）、`ambiguous_item`（题目问题）、`unknown`。

- 一次错误：给提示、换例子或分配另一家族题，不立即扩展知识图谱。
- 同一目标当前轮最近 3 个不同家族首答中至少 2 次判分错误：允许评估补丁。提示后答对的低证据分不自动算作“判分错误”。
- 只有 `prerequisite_gap`、置信度至少 0.8、引用至少两个满足上述条件的错误首答、明确指向补课概念时，才可自动提交补丁候选。
- 其他错因优先重讲本节点；低置信度只提建议，不自动改图。`ambiguous_item` 显示“题目待核查”，用户确认作废前不自动更改答案或抹除作答。
- 置信度只是保守分流条件，不能替代可核对的错误证据。

### 4.2 补丁约束

1. 补丁必须包含目标节点、目标版本、当前轮、证据、缺失概念 ID、新节点及依赖边；由本地课程服务校验后提交。
2. 单次最多插入 2 个节点；每个主节点同一 `remediationEpochId` 最多自动提交 2 个补丁，返回主节点开启新验证轮不重置上限；补丁深度最多 1 层，不在补丁上无限套补丁。
3. 同一目标、同一学习阶段、同一先修概念不得重复插入。若已有可用补课节点，复用该节点，不复制内容和成绩。
4. 知识依赖必须保持 DAG：无自环、无环、无不存在的端点。普通补丁只增加补充依赖，不删除或重排已有主线依赖。
5. 补丁和依赖的修改、版本递增及更新事件在同一事务提交；版本已变化的候选作废或重新生成，不强行覆盖。
6. 补丁达标后返回原节点，开启新的主节点验证轮。补丁成绩不直接当作原节点掌握证据。
7. 达到上限仍未通过时停止自动扩展，提供“换讲法”“暂停”“显式跳过”；不得以无限测验宣称“直至真正掌握”。
8. 自动应用后展示原因和“撤销”。撤销关闭此次补充依赖、归档专属补丁并保留历史；有其他引用的节点不删除。已消耗的自动补丁次数不因撤销返还，避免循环。

## 5. 内容与教学质量

### 5.1 内容契约

采用 `LessonDocument v1`：元数据、目标、顺序内容块、题目、来源和资源清单。正文是受限 Markdown；演示是带稳定 `blockId`、模板版本、参数和模型说明的声明式 JSON 配置。所有生成内容经过 Schema 与业务约束双重校验后才发布。详细字段与跨学科组件注册表见技术文档第 5 节。

- 禁止正文中的原始 HTML、任意脚本、动态组件源码及任意 SVG 注入；图形由本地已注册模板生成。可编辑程序只存在于专用 `code_lab` 中，用户显式运行后进入独立受限环境，不能在课文渲染时执行。
- 不在流式 JSON 尚未完成时执行渲染器。失败可修复一次，仍不合格则保留现有版本并显示错误。
- 每节点至少包含目标、核心解释、一个已解示例、练习与简短回顾；初始每目标至少准备 3 个题目家族，不够时按需补充。
- 题目必须有唯一 ID、所属目标、家族、判分规则和解析；未判分前普通学习界面不下发答案键。
- 已生成正文版本不可原地修改；新版本保留来源与版本关联，旧作答始终绑定原题目版本。

### 5.2 全学科渲染与计算实现

| 能力层 | 一期方案 | 正确性与规模边界 |
| --- | --- | --- |
| 公式、反应式与推导 | Markdown + KaTeX/mhchem + 分步骤推导块 | 排版不等于证明；化学配平核对原子/电荷守恒，不声称预测任意反应 |
| 小学教具与二维构造 | 受控 SVG、JSXGraph，分数块/数轴/尺规构造模板 | 约束驱动拖动，退化图形明确提示；不执行模型生成的脚本 |
| 三维几何与场 | Three.js/React Three Fiber，曲面、截面、向量场和内置几何体 | 旋转/缩放/切片，限制网格与采样；同时提供截面与数值说明 |
| 函数、矩阵、统计与信号 | 安全表达式解释器、固定数值内核、ECharts | 小矩阵消元/SVD、固定种子抽样、FFT；显示近似误差、定义域和单位 |
| 物理、电路与控制 | 解析模型优先，固定步长数值模板；Matter.js 仅用于适合的二维刚体 | 常见 ODE、理想电路/光学、低分辨率 PDE；不把通用刚体库当全部物理求解器 |
| 化学与分子 | mhchem、SmilesDrawer、3Dmol；经核对的本地结构库或用户导入结构文件 | SMILES 提供二维结构；三维须已有坐标或取回匹配结构，不能凭 SMILES 捏造构象 |
| 生物结构与过程 | 带来源的标注图/简化三维模型、分层过程图、Cytoscape 图网络 | 细胞与器官使用结构图，代谢/遗传使用过程或网络图；区分示意与测量数据 |
| 算法与系统 | 可信算法状态机、变量/内存/报文时序、隔离的 JS/Python/SQLite 实验 | 只模拟选定机制或运行小程序，不操作宿主网络和系统 |
| ML/DL | 可信数值算法 + TensorFlow.js 的小网络/张量计算 | 一期包含小模型真实计算、训练和可解释中间量；不依赖独立 GPU 或模型 API |
| 地图、时间线与通用关系 | 本地 GeoJSON、ECharts/SVG、关系图和带锚点资料 | 数据来源与年份可查；采用离线小范围数据，不要求在线地图平台 |

所有计算模板都需声明单位、初始条件、适用假设、随机种子（如适用）以及确定性/近似误差。验收采用解析答案、守恒量、已知算法输出或可信参考数据，不能只检查“页面画出来了”。

### 5.3 资料与质量边界

- 来源区分 `verified`（确实获取并核对的来源）和 `suggested`（模型建议、未核验）。一期不依赖 CLI 具有特定 Deep Research 或 Python 工具；本地演示计算由应用自己的受控组件完成。
- 解剖、生物结构、分子坐标、地图和演示数据集须记录来源、许可及有效版本；第一次获取经应用导入服务验证后缓存，后续演示不静默依赖外部 URL。
- 一期提供各学科的可复用模板和样例资源；当新主题没有匹配模板时，先尝试组合通用曲线、三维、网络、过程与标注组件，仍不足再明确标记待支持的具体能力。
- 每个样例记录是否人工复核、可验证的科学不变量和允许误差。任何未核验的新课程均不得自动继承样例的“已核验”标识。
- 学习者可以报告题目、公式或解释错误；修正生成新版本，并明确哪些证据受到影响。

## 6. 数据、隐私与可迁移性

课程内容、依赖图、个人进度、作答、聊天、笔记分别保存。SQLite 是状态事实来源，CLI 的会话历史仅帮助续聊；CLI 丢失会话不应导致学习记录丢失。

- 提问时才发送相关正文、图形参数和必要历史；不上传整套数据库、无关笔记、其他课程记录或 CLI 凭证。
- 首次使用说明：经 CLI 发给模型的内容受其服务的数据处理规则约束，“本地存储”不等于“推理完全离线”。
- 默认日志只含请求标识、状态、耗时、错误类别和 CLI 版本；诊断日志的原始内容须用户主动开启，导出前可预览。
- 课程支持归档；永久删除需确认并清理本应用管理的数据和资源，不擅自删除 CLI 管理的全局会话文件。

### 6.1 `.learn` 格式 v1

ZIP 包包含 `manifest.json`、`course.json`、`lessons/*.json`、`chapters/*.md` 和 `assets/`。`lessons/*.json` 是规范内容，Markdown 是便于阅读的派生文件；不能同时作为两个互相冲突的事实来源。manifest 声明所需模板/数据格式版本；分子坐标、模型、数据集、标注及复现实验必要的数据随包保存，可信 JS/WASM 运行库由应用管理，不能由课程包安装。

导出明确选择两种模式：

- **内容分享（默认）**：课程、已生成课文、题库和允许再分发的本地资源；不含个人进度、作答、聊天、笔记和设备信息。
- **个人备份**：在内容分享基础上加入个人学习记录、明确保存的实验快照和必要的历史资源；不含登录凭证和可直接续用的 CLI 会话标识，界面明确个人信息范围。

只导出已生成内容及完整大纲，未生成节点标记为 `not_generated`；不为导出静默触发批量模型调用。答案存在课程包中，因此该格式不提供防作弊保护。

导入默认“作为新课程学习”，重新分配本地 ID，清空个人进度；个人备份可选择“恢复为副本”，保留学习记录并重映射引用。两者均不覆盖现有课程。

必须检查格式版本、文件路径、文件哈希、引用完整性和解压限制；非法包不能留下半导入状态。未知主版本拒绝，已知旧版本经迁移后导入。Base64 不作为加密或分享方案。

### 6.2 其他导出与后续离线展示

一期 Markdown 导出包含已生成正文、公式、来源和图形静态替代文件；文件夹可再打包 ZIP，不承诺第三方编辑器还原交互。HTML/PDF 后续单独验收：内嵌或打包所需资源，动态组件提供静态降级，离线不包含在线导师能力。

## 7. 可靠性与性能要求

- 普通读取、本地判分在基准机上 p95 不超过 300ms；请求受理并显示排队/处理中 p95 不超过 1 秒。数据集为 10 门课程、合计 500 节点、10,000 条作答；记录基准机规格。
- 演示基准机为至少 4 核 CPU、16 GiB 内存、支持 WebGL2 的集成显卡，1080p 浏览器视口；不要求独立 GPU。库和实验按需加载，默认同时激活一个重型实验，离屏实验暂停。
- 缓存就绪后轻量参数联动 p95 不超过 200ms；标准规模三维/动画目标至少 30fps。数值计算、代码和训练放在独立 Worker/受限运行环境，界面可随时停止，停止请求 1 秒内响应。冷启动下载、计算进度和资源限制需可见。
- 无 WebGL 或设备性能不足时提供二维截面、静态多视图、表格和逐步数据等替代；不能让一个三维块阻断全课阅读。在支持的基准机上仍须通过真实交互演示验收，不能普遍用降级图顶替实现。
- 模型首字时间受网络、模型和额度影响，不承诺毫秒级。记录本机测得的启动、首字与完成耗时，作为优化依据。
- 一期全局最多运行一个 CLI 生成任务，最多排队 10 个；导师问答优先于尚未开始的批量生成，已开始任务不被抢占。
- 用户取消后 2 秒内进入取消状态，5 秒内回收本任务拥有的进程；已有学习数据保持一致。取消无法撤回已经发生的模型额度使用。
- 断线重连不自动重复提交。CLI 崩溃、超时、额度不足分别提示；不无上限重试或每秒重启。
- 中文输入法组合键不能误触发送；支持键盘操作、非颜色状态标识、图形替代说明。小屏幕可折叠导师和导航。

| A26 | 图形兼容与降级 | 基准机正常使用二维/三维/分子；无 WebGL、资源缺失、退化几何和计算超时有可读降级；不冒充演示成功 |
| A27 | 多学科资源往返 | 分子坐标、模型、数据集、标注图及演示参数随 `.learn` 完整往返，离线复现；所需可信运行库由应用管理而非课程包执行 |
| A28 | 模板与运行边界 | 模型只能选择已注册版本的模板；向渲染器注入未注册算法、JS/着色器或外部依赖被拒绝；code_lab 的显式受限运行单独按 A24 验收 |

## 9. 实施顺序

| 阶段 | 交付与退出条件 |
| --- | --- |
| M0 接入验证 | 固定 `agy` 兼容版本；完成真实事件样本、续聊、Schema、权限行为及失败/取消探针；A01/A02 的接入部分通过 |
| M1 公共底座与闭环 | 同源本地服务、SQLite、内容契约、组件注册表、作答/掌握/补丁、导师和恢复；跑通二维、三维、分子、Worker、代码隔离和小网络最小原型，暴露技术风险 |
| M2 数学、物理与工程 | 完成 S01～S11、S20 的模板、讲练路径及参考答案/数值校验；不是一期的最终发布范围 |
| M3 化学、生物与通用资料 | 完成 S12～S15、S21～S22，补齐结构资源、过程图、地图/时间线与离线缓存 |

M0～M5 均属于一期；可以在阶段间提供预览版，但不得将 M1/M2 的有限学科原型标记为全科一期完成。排期结合 M0/M1 的运行库原型结果和团队投入估算，优先通过共享组件降低工作量，不以未经验证的固定周数承诺全学科交付。
