# M1 公共底座与闭环规格

清空导师对话：确认后以事务清理当前会话的消息、上下文、任务、scope和SSE历史，并解除供应商会话绑定；保留课程、笔记、作答和其他会话。进行中/排队任务及正在退出的进程阻止清空。下次提问不携带旧history或conversationId。用户已确认仅需本地清空，agy内部会话不删除，不修改其私有数据库/文件。

导师进度：聊天运行预算为300秒，排队不计时，CLI自身与监督器使用同一预算。Given agy init/step_update/result，Then 显示真实的连接、输入、处理、工具、回复及等待退出阶段，带步骤号、状态和时间；不显示原始工具参数、日志或内部推理文本。相同步骤增量去重，最多保留最近80步，刷新通过服务端快照恢复。无新步骤时只显示距最近更新的时长，不伪造进展；取消或终态后不接受迟到步骤。

课程删除：Given 我的课程列表中的课程，When 点击删除并确认，Then 删除该课程及其学习记录、笔记和导师会话，立即更新列表，刷新后不再出现。取消确认不发送删除请求。活动任务或课程版本冲突时拒绝删除并显示原因；不影响其他课程和已导出的备份文件。

修复验收：Given 大纲高度大于正文，When 打开桌面工作室，Then 正文及导师列顶端与网格顶端对齐，不被垂直自动外边距推到下方。Given 聊天超时、取消或重启中断，Then 导师占位消息进入相同终态，不继续显示等待回复；刷新后仍然如此。Given 普通导师提问，Then 使用提交时的正文与实验上下文直接回答，不要求规划、代码任务或文件探索；真实 CLI 验证首轮与续聊。

关联 A03–A18、A29/A30。服务端是课程、作答和进度的唯一状态源；所有写操作由领域事务处理。

- Given同一请求标识，When重复提交，Then相同内容返回原结果、不同内容冲突；判分与事件原子提交。
- Given当前轮不同家族首答，When窗口为1/1、2/2、2/3、3/5、4/5，Then仅2/2和4/5达标；曝光提示后正确也记0。
- Given两个有效错误且高置信先修缺口，When提交补丁，Then校验版本、DAG、同epoch预算和概念去重；撤销不返还次数。
- Given补课完成，When回到主节点，Then新cycle沿用epoch且不迁移补课成绩。
- Given课程正文改版，When旧assignment提交，Then拒绝旧轮作答。
- Given服务重启或断线，When重新打开，Then通过持久消息及游标恢复，不自动重跑模型任务。
- Given错误Origin/Host、无Cookie/CSRF或无MCP凭证，When访问业务入口，Then拒绝且不暴露个人数据。
- Given 已调整实验参数和步骤，When 保存实验快照、刷新后恢复，Then 从服务端恢复相同正文版本、模板版本的参数、步骤及选择，暂停播放并重新计算观察值；旧版本快照不应用到新正文。

## 退出与单写恢复（A15/A29）
Given 活动写实例，When 第二实例启动，Then 拒绝且保留原实例。Given Ctrl+C、启动失败或退出清理异常，Then 必须释放数据库与锁；异步退出最多等待10秒。Given 进程被强制终止，When 下次启动，Then 自动恢复遗留标记。旧格式 PID 锁仅在确认 PID 不存在时恢复；存活或无法确认时拒绝。
