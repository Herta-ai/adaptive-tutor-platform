# M5 集成交付规格

A01–A30全部通过后才可发布一期。内容包去除个人记录，backup保存个人学习状态；导入始终创建新课程和新ID，不能恢复CLI供应商会话。

Given恶意ZIP路径、重名、大小/压缩比超限或hash失配，When校验，Then拒绝且不创建可见课程。Given正常无外部资源包，Whenfresh或restore_copy导入，Then引用一致、进度按模式重建。性能和全学科资源往返仍需独立验收。

Given 已分配补充题并作答、部分题目已作废，When 导出 backup 后 restore_copy，Then 补充题、家族关系、作答引用和作废状态完整恢复。题库以当前持久记录为准，历史正文保持原始内容；导入不能用正文中的旧状态覆盖题库。题库中的课程、节点、目标、正文版本及家族映射必须一致，否则拒绝导入。旧包未提供独立题库时，从正文提取题目以兼容已有预览包。

Given 同节点同 familyKey 的补充或重写题目，When 发布及导入后再次补题，Then 延用同一 familyId，不因导入更换节点 ID 而重新计算家族身份。
